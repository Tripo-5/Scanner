Instructions

    Setup:
        Clone the repository.
        Run pip install -r requirements.txt to install dependencies.

    Prepare Files:
        Add your proxy list in a text file (proxy.txt).
        Place CSV files with IP ranges in the ip_ranges directory organized by country.

    Run the Script:
        Execute python main.py to launch the menu.
        Follow the on-screen prompts to load proxies, manage hosts, test connectivity, and perform scans.

    Menu Options:
        Load proxies, test their availability, and use them for scanning.
        Load IP ranges and generate host lists.
        Test SSH connectivity and scan for banners.
        Identify vulnerabilities, clear files, and automate brute-forcing.

    Output:
        Results are saved in text files for further analysis.
